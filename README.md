# שמורה

כל מה ששמרת מהרשתות, במקום אחד.

אפליקציית PWA לשמירת סרטונים ולינקים מאינסטגרם, יוטיוב, פייסבוק וטיקטוק. במקום לזרוק לינקים לקבוצת וואטסאפ עם עצמך ולשכוח, משתפים אל "שמורה" והכול מחכה בפיד מסודר: קטגוריות, תגיות, חיפוש ותאריכים.

## איך זה עובד

- **שיתוף מכל אפליקציה (אנדרואיד):** אחרי התקנת האפליקציה מכרום, "שמורה" מופיעה בתפריט השיתוף של אינסטגרם, יוטיוב ופייסבוק.
- **תמונות מקדימות אמיתיות:** יוטיוב וטיקטוק דרך תמונת הסרטון, אינסטגרם ופייסבוק דרך ההטמעה הרשמית שלהם (embed), שמציגה את הקאבר האמיתי של הריל בלי שום מפתח.
- **סיווג אוטומטי:** זיהוי קטגוריה לפי מילות מפתח, בחינם ובלי רשת. ומי שמדביק מפתח Gemini של גוגל בהגדרות מקבל סיווג חכם: קטגוריה, תגיות וכותרת נקייה לכל סרטון. המפתח נשמר רק על המכשיר, אף פעם לא בקוד.
- **הנתונים על המכשיר:** הכול נשמר ב-IndexedDB בטלפון. אין שרת, אין חשבון. יש ייצוא וייבוא גיבוי JSON בהגדרות.
- **עובד גם בלי אינטרנט:** Service Worker שומר את האפליקציה והתמונות במטמון.

## התקנה על הטלפון (אנדרואיד)

1. פותחים את הכתובת בכרום.
2. תפריט ⋮ ובוחרים "הוספה למסך הבית" או "התקנת אפליקציה".
3. מרגע ההתקנה, "שמורה" מופיעה בתפריט השיתוף של כל אפליקציה.

## מבנה

- `index.html`: כל האפליקציה, בלי תלות בכלי build
- `manifest.json`: הגדרות PWA כולל share_target
- `sw.js`: מטמון לעבודה בלי רשת
- `icons/`: אייקוני האפליקציה
